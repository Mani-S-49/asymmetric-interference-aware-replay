# Asymmetric Interference-Aware Replay for Language-Incremental Continual Learning

## Research objective

Investigate whether replay weighted by directional, script-aware cross-lingual interference can reduce forgetting in language-incremental continual learning.

The research plan at `..\1 . Research_Plan\research_plan.md` is the authoritative specification for this implementation.

## Working principles

- Follow the research plan's phases, methods, baselines, metrics, ablations, and checkpoints.
- Implement and test the required components in VS Code.
- Run experiments to evaluate both correctness and research performance.
- Use Git and GitHub for version control and code synchronization.
- Use Kaggle for GPU experiments where appropriate.
- Use Weights & Biases or the selected experiment tracker to record runs.
- Preserve configurations, seeds, logs, metrics, plots, and reports.
- Reuse shared components across phases and run regression tests after changes.
- Record failures and negative results; do not declare a checkpoint passed without evidence.

## Phase sequence

- Phase 0: Onboarding
- Phase 1: Harness construction
- Phase 2: Baselines
- Phase 3: Prior comparison
- Phase 4: Method development and matched-budget comparison
- Phase 5: Ablations
- Phase 6: Scaling
- Phase 7: Learned prior (stretch goal)
- Phase 8: Writing

The phase labels above follow the research plan.
